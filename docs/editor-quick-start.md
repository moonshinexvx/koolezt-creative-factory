# Editor quick start

## First time

1. Double-click **KooleztCreativeFactoryRenderWorker-Setup.exe**.
2. Click **Next**, then **Install**.
3. Enter the Setup Code supplied by the owner.
4. Confirm **Start automatically with Windows** is enabled.
5. Click **Finish**.

## Daily workflow

1. Open https://creative.printwlove.com and sign in with your approved email.
2. Create or open a project.
3. Prepare and approve the concept.
4. Generate videos in the external tool selected for each scene.
5. Upload, review, and accept all three scene videos.
6. Prepare, generate, review, and accept narration.
7. Mark editor assets complete, then click **Render Final Video**.
8. Preview the completed candidate.
9. Choose **Render Another Version** if needed.
10. Click **Submit for Owner Review**.

The Render Worker starts with Windows and works in the background. No command line, server address, token, Node.js, or FFmpeg setup is required.
## Variant Factory

1. Open a project with three accepted scenes and an accepted voice.
2. Open **Creative Variants** and review the optional hook pool.
3. Choose **Create & Render 12 Variants**.
4. A compatible Windows Render Worker 1.2.1 renders the batch sequentially.
5. Preview or download each ready MP4 and download the batch manifest when available.

Variant renders are separate advertising test assets; they never replace the project's published final.
